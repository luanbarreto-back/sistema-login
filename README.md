Sistema de Login

Projeto simples de sistema de login desenvolvido com HTML, CSS e JavaScript.

Funcionalidades
- Cadastro de usuário
- Login de usuário
- Validação de dados
- Armazenamento no navegador (localStorage)

#Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

Estrutura do projeto

sistema-login/

index.html
cadastro.html
style.css
script.js


Como executar
1. Baixe o projeto
2. Abra o arquivo `index.html`
3. Utilize no navegador

Observações
- Projeto para estudo
- Sem banco de dados real
